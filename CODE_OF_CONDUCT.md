# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers to LCA and to AI alike, and keep criticism focused on ideas and code.

Report unacceptable behaviour to Ashira Benchimol through her GitHub profile, [github.com/ashirabench](https://github.com/ashirabench). All reports will be handled confidentially.
